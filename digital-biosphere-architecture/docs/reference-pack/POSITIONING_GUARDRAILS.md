# Positioning Guardrails

## 可以怎么说

- Digital Biosphere Architecture = canonical architecture hub
- Agent Evidence Profile (AEP) = concrete execution-evidence entry
- `verifiable-agent-demo` = walkthrough demo
- `aro-audit` = audit plane
- EDC Java spike = frozen augmentation-layer validation artifact
- EDC is a scenario-specific augmentation environment, not the research mainline

## 不要怎么说

- do not describe the work as a better tracing tool
- do not describe it as an observability export format
- do not describe EDC Java spike as an EDC replacement
- do not describe the EDC line as a connector product line
- do not describe the project as a generic logging platform
- do not imply that the frozen EDC spike is the new mainline
- do not collapse architecture, evidence, demo, and audit into one repo role
