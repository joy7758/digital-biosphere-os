# One-Line And Three-Line Versions

## 中文一句话版

Digital Biosphere Architecture 是总架构入口，Agent Evidence Profile
(AEP) 是具体执行证据入口，`verifiable-agent-demo` 提供最短 walkthrough，
`aro-audit` 负责事后审计与一致性检查。

## English One-Line Version

Digital Biosphere Architecture is the architecture hub, Agent Evidence Profile
(AEP) is the concrete execution-evidence entry, `verifiable-agent-demo` is the
walkthrough, and `aro-audit` is the audit plane.

## 中文三句话版

Digital Biosphere Architecture 是整个项目的 canonical architecture hub，
用于说明层次、仓库边界和主导航。Agent Evidence Profile (AEP) 是具体的
execution-evidence entry，负责把运行过程打包成可独立验证的 evidence
bundles。`verifiable-agent-demo` 提供最短 walkthrough，`aro-audit`
负责 post-execution review、receipts 和 conformance。

## English Three-Line Version

Digital Biosphere Architecture is the canonical architecture hub for repository
boundaries and system navigation. Agent Evidence Profile (AEP) is the concrete
execution-evidence entry for portable, independently verifiable evidence
bundles. `verifiable-agent-demo` is the walkthrough, and `aro-audit` is the
audit plane for post-execution review, receipts, and conformance.

## EDC Java Spike

EDC Java spike should be described as a frozen augmentation-layer validation
artifact.

更完整一点的说法是：

- EDC Java spike is a frozen augmentation-layer validation artifact.
- It validates a scenario-specific control-plane augmentation path.
- It is not the research mainline and not an EDC product line.
