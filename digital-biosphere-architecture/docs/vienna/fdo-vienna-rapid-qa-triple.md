# FDO Vienna Rapid Q&A Triple

## Q1

**English**  
What is this in one sentence?

**中文**  
这个项目用一句话怎么说？

**English**  
A layered governance architecture for autonomous AI systems.

**中文**  
一套面向自治 AI 系统的分层治理架构。

---

## Q2

**English**  
Is this already an official FDO standard?

**中文**  
这已经是官方 FDO 标准了吗？

**English**  
No. It is a discussion-ready architecture with candidate FDO-facing entry artifacts.

**中文**  
不是。它是一套已经准备好进入讨论的架构，其中包含面向 FDO 的候选入口构件。

---

## Q3

**English**  
What is your strongest profile candidate?

**中文**  
你们最强的 profile 候选件是什么？

**English**  
Start with the architecture hub. From there, Agent Evidence is the concrete execution-evidence entry, Verifiable Agent Demo is the shortest walkthrough, and ARO-Audit is the post-execution audit control plane.

**中文**  
先从 architecture hub 开始；然后 Agent Evidence 是具体证据入口，Verifiable Agent Demo 是最短演练，ARO-Audit 是执行后的审计控制平面。

---

## Q4

**English**  
Why not merge everything into one profile?

**中文**  
为什么不把所有内容合成一个 profile？

**English**  
Because the layers perform different functions.

**中文**  
因为不同层承担的是不同功能。

**English**  
Some define object structure, some define semantics, some verify execution, and some provide runtime enforcement.

**中文**  
有的定义对象结构，有的定义语义，有的验证执行，有的提供运行时约束执行。

---

## Q5

**English**  
What kind of feedback are you looking for?

**中文**  
你最希望得到什么反馈？

**English**  
Feedback on profile boundaries, terminology alignment, and FDO-facing interpretation.

**中文**  
关于 profile 边界、术语对齐，以及面向 FDO 的解释方式的反馈。
