# FDO Vienna 3-Minute Triple Script

## 3-Minute Script

**English**  
The Digital Biosphere Architecture is not a single AI product and not just a demo.

**中文**  
Digital Biosphere Architecture 不是一个单独的 AI 产品，也不只是一个演示。

---

**English**  
It is a layered governance architecture for autonomous AI systems.

**中文**  
它是一套面向自治 AI 系统的分层治理架构。

---

**English**  
As AI systems become more autonomous, we need a clearer way to describe not only what they can do, but who they are, how they interact, what constraints apply at runtime, what actually happened during execution, and what evidence remains afterward.

**中文**  
随着 AI 系统越来越自治，我们需要一种更清晰的方式，不仅描述它能做什么，还要描述它是谁、它如何交互、运行时受什么约束、执行过程中实际发生了什么，以及事后还能留下什么证据。

---

**English**  
That is why we organized the work into five layers.

**中文**  
这就是为什么我们把整项工作组织成五层。

---

**English**  
POP defines a structured and versioned persona object.

**中文**  
POP 定义了一个结构化、版本化的人格对象。

---

**English**  
AIP defines bounded semantics for intent, action, and result exchange.

**中文**  
AIP 定义了关于 intent、action 和 result 交换的有边界语义。

---

**English**  
Token Governor provides runtime controls such as policy and budget enforcement.

**中文**  
Token Governor 提供运行时控制，例如策略约束和预算执行。

---

**English**  
MVK provides deterministic checks, replay validation, and tamper-detection surfaces.

**中文**  
MVK 提供确定性检查、重放验证和篡改检测界面。

---

**English**  
ARO-Audit defines bounded and reviewable evidence artifacts with integrity and provenance-oriented references.

**中文**  
ARO-Audit 定义了具有完整性和来源导向引用的、有边界且可审阅的证据构件。

---

**English**  
We are not claiming that all of these are already official FDO artifacts.

**中文**  
我们并不是在声称这些都已经是官方 FDO 构件。

---

**English**  
Publicly, readers should start from the architecture hub, then route to Agent Evidence for the concrete execution-evidence entry, Verifiable Agent Demo for the shortest walkthrough, and ARO-Audit for post-execution review.

**中文**  
对外阅读时，应先从 architecture hub 进入，再分别去 Agent Evidence、Verifiable Agent Demo 和 ARO-Audit。

---

**English**  
POP is a persona object profile candidate.

**中文**  
POP 是人格对象 profile 候选件。

---

**English**  
AIP is an interaction semantics profile candidate.

**中文**  
AIP 是交互语义 profile 候选件。

---

**English**  
ARO-Audit is an audit evidence profile candidate.

**中文**  
ARO-Audit 是审计证据 profile 候选件。

---

**English**  
MVK is a conformance and verification surface.

**中文**  
MVK 是一个 conformance 和 verification 界面。

---

**English**  
Token Governor is a governance reference implementation.

**中文**  
Token Governor 是一个治理参考实现。

---

**English**  
Our contribution is to provide a minimal architecture matrix for discussing governed autonomous AI systems in terms of object, profile, conformance, evidence, and implementation.

**中文**  
我们的贡献，是提供一个最小架构矩阵，用于从 object、profile、conformance、evidence 和 implementation 这些维度来讨论受治理的自治 AI 系统。
