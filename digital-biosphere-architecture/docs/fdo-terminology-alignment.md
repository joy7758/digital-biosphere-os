# FDO Terminology Alignment

This note aligns Digital Biosphere Architecture terms with FDO-facing discussion language.

## Terms

### Object
A bounded, interpretable artifact with stable structure.

### Profile
A constrained representation rule for a defined object class.

### Conformance Surface
A validation or verification boundary through which claims can be checked.

### Evidence Artifact
A bounded audit-oriented export containing references needed for review.

### Reference Implementation
A runnable implementation that demonstrates how a layer behaves in practice.

## Architecture Mapping

- POP → object/profile candidate
- AIP → semantics/profile candidate
- ARO-Audit → evidence profile candidate
- MVK → conformance surface
- Token Governor → reference implementation
