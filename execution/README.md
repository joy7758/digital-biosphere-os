# DBOS-EXP-0001 执行层

本目录实现 `DBOS-EXP-0001` 的确定性、受限执行路径。

智能体可读边界：

- `dbos_exp_0001.py` 只接受三个显式子命令：环境采集、冻结快照捕获、已授权实验执行。
- 环境采集只读取允许的操作系统、Python、依赖、配置摘要与基础硬件事实；不读取环境变量、凭据、密钥、个人数据或外部存储内容。
- 快照捕获只读取本项目内的显式目录，生成规范化清单和确定性归档。
- 实验执行只运行冻结清单中的验证器，并只写入实验专属证据目录。
- Runner（执行器）不是 Agent（智能体）、Runtime（运行时实例）或 Digital Organism（数字生命体）。
- 局部结构验证通过不等于独立验证、能力批准、权限授予、生产适用性或数字生命形成。

所有子命令都采用 fail-closed（失败关闭）策略：输入、摘要、授权或验证出现缺口时，以非零状态退出，并保留已有材料。
