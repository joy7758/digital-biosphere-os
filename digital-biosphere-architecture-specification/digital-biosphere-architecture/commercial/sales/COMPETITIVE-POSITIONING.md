# Competitive Positioning / 竞争定位

| Customer need | Primary category | TITMAS recommendation |
|---|---|---|
| Trace, prompt debugging, LLM evaluation | Observability / LLMOps | `NOT_PRIMARY` |
| General RBAC/ABAC | Authorization platform | `NOT_PRIMARY` |
| Prompt injection, content filtering, AI firewall | AI security gateway | `NOT_PRIMARY` |
| Agent creation and orchestration | Agent framework/runtime | `NOT_PRIMARY` |
| Critical action control plus authorization binding, portable Receipt and independent Audit | TITMAS candidate scope | `CONDITIONAL` |

TITMAS 的差异化候选是跨 Agent 行动控制与证据互操作，不是“唯一签名回执”。选择仍需核验实际工作流、数据和部署约束。
