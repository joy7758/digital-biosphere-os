# Design Partner Interview Guide / 设计伙伴访谈提纲

只记录非保密问题陈述：

1. 哪个 Agent 工作流最难回答“谁做了什么、依据什么、是否恢复”？
2. 现有日志、Trace、CI 或审计材料缺少什么？
3. 哪个错误决定造成最高复核成本？
4. 谁拥有最终授权、验收和停止权？
5. 哪些字段绝不能离开客户边界？
6. 首次价值应在几步、多久内出现？
7. 哪类 Receipt 或 Audit 视图可支撑实际复核？
8. 什么结果会让客户终止试点？
9. 固定费用、实施费用、保留和支持应如何分开理解？
10. 什么证据足以进入下一阶段，什么仍需人工判断？

不得索取 API Key、客户名称、私有仓库内容、个人信息或生产样本。
