# Data Boundary Questionnaire / 数据边界问卷

客户与 Human Owner 必须共同回答：

- 数据 Owner、处理目的、合法来源和允许用途是什么？
- 是否包含个人信息、敏感个人信息、客户数据、秘密、生产数据或受监管数据？
- 哪些字段可进入 TITMAS，哪些仅可保留引用或摘要？
- 数据位于何处，是否存在跨境、第三方或模型 Provider 传输？
- 保留时间、删除、导出、备份和恢复要求是什么？
- 谁可读取、验证、撤销和批准范围变化？
- 停止或退出后如何验证删除/返还？

缺失、矛盾或 `UNKNOWN` 时保持 fail-closed。问卷不构成数据处理授权。
