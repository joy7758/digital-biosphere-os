# Exit and Data Return Runbook / 退出与数据返还运行手册

1. Freeze new intake and preserve the final bounded state.
2. Revoke or expire Pilot credentials and verify access is absent.
3. Export contractually agreed Receipts, Audit records and usage summary.
4. Return or delete customer-scoped material according to the approved schedule.
5. Handle backups and residual metadata under declared retention exceptions.
6. Record success, failure or `NOT_ASSESSED` for every deletion/return action.
7. Close access only after Human review; retain required legal and security records separately.

No destructive operation is authorized by this document. Actual deletion requires exact target resolution, customer scope, Human authorization and recoverability review.
