# TITMAS Monitor Pilot 建议书草案

`STATUS=NOT_AVAILABLE_REQUIRES_CUSTOMER_SPECIFIC_SOW`

## 候选范围

- 一个关键软件交付工作流；
- 1–3 个 Agent；
- 最长 30 个自然日；
- 合成首次价值，再进入经书面批准的最小元数据；
- 周度发现复核、最终限制和 ROI 输入报告；
- 退出时撤销凭据并记录数据返还/删除状态。

## 交付物

Shadow Gate Result、技术 Receipt、Audit 时间线、用量摘要、已知限制、集成/操作投入记录。

## 明确不提供

真实阻断、自动批准、代执行、模型正确性保证、正式认证、生产 SLA、无限数据保留或未批准外部模型处理。

价格、容量、支持窗口、数据范围和验收必须写入经 Human 审查的 SOW。当前不构成报价或可售状态。
