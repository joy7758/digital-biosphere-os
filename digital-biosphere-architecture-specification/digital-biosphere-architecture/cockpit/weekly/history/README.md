# Weekly Snapshot History

This directory is reserved for immutable, explicitly admitted weekly snapshots.

- A new week creates a new snapshot identity.
- Existing snapshots MUST NOT be overwritten.
- Absence of a previous snapshot produces `NOT_ASSESSED_NO_PREVIOUS_SNAPSHOT`.
- History is an evidence reference layer, not a truth, authority, permission, or execution object.
- The v0.1 prototype does not automatically write history.
