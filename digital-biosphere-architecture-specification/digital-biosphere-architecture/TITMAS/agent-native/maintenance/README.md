# Agent Maintenance Protocol

A bounded `AGENT_MAINTENANCE_OPERATOR` may inspect links, schemas, registries,
fixtures, task expiry, version references and example drift; propose a
non-destructive correction; run local CI commands; and produce a report.

It may not merge, release, promote maturity, enlarge scope, delete history,
change Ownership or Authority, deploy, or contact an external party.

Every action requires an unexpired lease, exact scope, source revision,
rollback path, evidence binding and review.
