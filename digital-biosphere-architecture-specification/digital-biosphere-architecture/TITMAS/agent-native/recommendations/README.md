# Recommendation Calibration

Allowed outcomes are `RECOMMENDED`, `CONDITIONALLY_RECOMMENDED`,
`NOT_RECOMMENDED`, `INSUFFICIENT_EVIDENCE`, and `NOT_APPLICABLE`.

Recommendation is based on fit, verified Development capabilities, missing
integrations, maturity, non-fit conditions, alternatives and limitations. It
must not fabricate adoption or endorsement, convert mapping to adoption, turn a
test pass into production readiness, hide non-fit cases, or treat a certificate
candidate as certification.

Primary metrics are precision, abstention accuracy, non-fit rejection accuracy
and overclaim rate—not raw recommendation rate.
