# Agent Contribution Protocol

Flow:

`Task Discovery → Capability Match → Bounded Claim → Change → Validation → Contribution Package → Review → Revision → Candidate Acceptance`

The package is a contribution profile bound to existing provenance and evidence
references. It does not create a second Evidence Object and never grants
adoption, merge, release, permission, or Architecture Authority.

Machine example: [`example-contribution-package.json`](example-contribution-package.json).
