# Release Checklist

Preparation only; this checklist does not authorize a Release.

- [ ] exact version and immutable source selected
- [ ] registries, schemas, links and tests pass
- [ ] security/privacy findings adjudicated
- [ ] Maintainer and release responsibility assigned
- [ ] migration and rollback documented
- [ ] maturity and limitations are accurate
- [ ] public claims reviewed
- [ ] Human Release Decision recorded
- [ ] tag and announcement separately authorized
