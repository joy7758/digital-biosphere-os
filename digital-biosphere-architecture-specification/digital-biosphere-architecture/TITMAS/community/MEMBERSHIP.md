# TITMAS Role and Membership Model

Status: `ROLE_MODEL_PREPARED_NO_ASSIGNMENTS`

| Role | Purpose | Entry evidence | Authority limit |
|---|---|---|---|
| Explorer | learns and reproduces examples | none | no project role |
| Contributor | submits bounded changes | accepted contribution | no merge or decision authority |
| Integrator | proposes Adapter/Profile work | reproducible integration contribution | no external-system authority |
| Specification Contributor | drafts normative changes | accepted proposal work | cannot adopt own proposal |
| Reviewer | performs scoped review | assigned review contract and evidence | recommendation only |
| Maintainer Candidate | prepares for maintenance | sustained work and independent review | not a Maintainer |
| Maintainer | maintains an approved surface | explicit Human Decision, term and scope | no DBA/DBOS/SAEE authority inheritance |
| Interim Steward | time-bounded continuity role | explicit Human Decision and expiry | cannot make permanent role or authority changes |

Roles are not self-assigned, inherited from AI use or created by contribution
count. Each assignment requires scope, start, expiry/review date and revocation.
