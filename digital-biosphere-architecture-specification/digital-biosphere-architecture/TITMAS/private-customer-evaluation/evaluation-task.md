# Private Agent Evaluation Task Candidate

An authorized future Agent would receive only this bundle and answer:

1. What problem does the candidate service claim to address?
2. When should it be recommended, conditionally recommended, rejected or
   abstained from?
3. Which claims are unsupported by the bundle?
4. Can the synthetic request and response be checked against the contract?
5. What additional evidence would be required before commercial use?

No repository write, core source access, network request, Provider call,
customer record or public report is authorized.
