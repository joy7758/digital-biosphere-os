# TITMAS Website Update Constitution v0.1

Status: `SITE_GOVERNANCE_BASELINE`

## Default decision rule

When a website choice is required, review the current official OpenAI and
OpenTelemetry patterns first.

- Use OpenAI as the primary reference for audience-facing information
  architecture, Research overview/index separation, Newsroom categories,
  release notes, developer updates, progressive disclosure, and concise
  announcements.
- Use OpenTelemetry as the primary reference for announcement dates and expiry,
  document-level maturity, Specification/Implementation/Contrib separation,
  versioning, stability, deprecation, provenance, and documentation
  contribution workflow.

## Decision sequence

1. Classify the website change.
2. Verify current TITMAS truth.
3. Check the relevant official OpenAI pattern.
4. Check the relevant official OpenTelemetry rule.
5. Preserve TITMAS authority and non-equivalence boundaries.
6. Record source, date, status, limitations, and any superseded item.
7. Validate Chinese, English, and machine-readable surfaces together.

## Conflict rule

Verified TITMAS truth and governance boundaries override reference style.
Neither reference can create a product, implementation, permission, authority,
release, certification, customer claim, or production status.

## Human gate

Human review remains required for a new product or commercial-offering claim,
production or certification claim, authority/permission/execution change,
breaking stable public interface, or legal/security/privacy commitment.

## Non-affiliation

This constitution uses official public information as a reference. It does not
claim affiliation with or endorsement by OpenAI, OpenTelemetry, CNCF, or their
contributors.
