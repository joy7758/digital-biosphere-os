# China Generative AI Service Applicability

Status: `HUMAN_LEGAL_REVIEW_REQUIRED`

Primary source: https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm

| Scenario | Candidate status | Reason |
|---|---|---|
| A. TITMAS controls actions and does not generate public content | `LIKELY_NOT_APPLICABLE` to that bounded function | no public generative-content service is offered by the Gate itself |
| B. TITMAS uses a filed domestic model for internal bounded evaluation | `CONDITIONALLY_APPLICABLE` | application registration, disclosure and provider responsibilities need review |
| C. TITMAS offers public generative functionality in China | `LIKELY_APPLICABLE` | public-facing generation changes the service boundary |
| D. Customer invokes a model only in its private environment | `CONDITIONALLY_APPLICABLE` | customer/provider roles and actual audience determine obligations |
| E. External model receives only synthetic/public validation data | `CONDITIONALLY_APPLICABLE` | provider and cross-border policies still require records |
| F. Foreign model processes China customer data | `PROHIBITED_BY_DEFAULT` | separate legal and cross-border review required |

No public generative feature is required for D29. A future public function must
review model filing/application registration, model-name disclosure, complaint
entry, input protection and AIGC labeling before release.
